# USER.md — House Rules

not already say. Empty is the normal state, and an empty file means the
standing orders stand unqualified.

**You never write here.** This deployment has no write tool, and something said
in a conversation is not a rule — it is a thing said in a conversation.

**A house rule never beats *Safety* in `AGENTS.md`.** If the two disagree, the
standing orders win and you say plainly that they do.
